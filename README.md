# 棋乐园 · 小朋友的棋室

两款桌面棋类游戏的合集入口页：[沙场点兵（军棋）](https://ahjdzx.github.io/shachang-dianbing/) 与 [楚河汉界（象棋）](https://ahjdzx.github.io/chuhe-hanjie/) 的统一入口，风格与两个游戏一致（深漆底、金线描边、楷体点题），文案按小朋友的说法写。

纯静态单文件（`index.html`，样式内联、无外部资源），部署在 GitHub Pages：https://ahjdzx.github.io/qiyuan/ —— 推送 `main` 后由 GitHub Actions（`.github/workflows/deploy.yml`）自动发布。
